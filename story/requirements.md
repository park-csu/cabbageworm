# 프로젝트 요구 사항

처음에 생각한 조건은 세 가지였습니다.

1. **기존 기능을 살린다.** 예전 노트북은 요즘 제품에 비해 포트와 상태 표시등이 훨씬 많습니다. 특히 Tablet 계열에는 펜 입력을 받는 터치 패널(디지타이저)이 달려 있고, 화면을 돌려 접으면 태블릿으로도 쓸 수 있습니다.
2. **ThinkPad의 생김새를 지킨다.** 키보드 한가운데 빨간 점이 박힌, 투박한 검은 벽돌 같은 모습 말입니다.
3. **다음 업그레이드가 가능해야 한다.** 메인보드를 직접 설계하는 방안은 일찌감치 접었습니다. 혼자 감당하기에는 비용이 너무 크고, 요즘의 고주파 회로를 설계하기도 어렵습니다.

저도 임기응변으로 이것저것 만들어 붙이는 걸 좋아하지만, 나중에 손보려면 시간이 많이 듭니다. 그런 개조는 최소화하고, 기존 문서가 있으면 활용하고 없는 부분은 직접 기록하기로 했습니다. 부품도 이미 나와 있고 장기 지원을 받을 수 있는 플랫폼에서 가져오기로 했습니다. 미니 PC용 보드나 Raspberry Pi, Orange Pi 같은 보드도 후보에서 뺐습니다. 제가 앞으로 주력으로 쓸 기기에 맞지 않는 점이 있을 수 있어서입니다.

후보로 남은 건 MNT Rework와 Framework였습니다. 둘 다 비교적 개방적이고 등장한 지 오래되지 않은 프로젝트입니다. 그중 Framework는 세대가 바뀌어도 부품을 이어 쓰기 좋고 사용자층도 더 넓습니다. 오래 쓸 기기라면 나중에도 부품을 구하고, 적어도 커뮤니티의 도움을 받을 수 있어야 합니다. 그래서 핵심 부품만이라도 Framework와 호환되도록 설계하기로 했습니다.

## 부품 구성

1. **그대로 쓸 부품**은 케이스, 펜 디지타이저, 상태 표시등입니다.
2. **새로 넣을 부품** 중 메인보드, 확장 카드, 카메라, 배터리, 오디오 보드는 Framework 제품을 씁니다. 스피커와 디스플레이 패널은 다른 제품을 씁니다.
3. **기존 부품과 새 부품을 연결할 때** 키보드, 터치패드, 펜 디지타이저, 화면부의 표시등과 버튼에 각각 어댑터가 필요합니다. 디스플레이와 스피커 연결용 케이블도 필요합니다.

## 디스플레이 선택

부품 구성을 정하고 나서 가장 먼저 디스플레이를 알아봤습니다. 제게는 오래된 CPU의 성능만큼이나 순정 화면의 낮은 해상도가 아쉬웠습니다. 맞는 디스플레이를 구할 수 없다면 이 개조의 매력도 그만큼 줄어듭니다.

Panelook에서 찾아보니 순정 화면과 치수가 딱 맞는 패널이 있었습니다. 여러 Panasonic 노트북에 쓰인 12.1인치, 1920 × 1200 해상도의 패널입니다. 모델은 두 가지인데, 시중에서 찾을 수 있었던 건 CLAA121FP01뿐이었습니다. G121UAN01.0은 좀처럼 보이지 않더군요.
