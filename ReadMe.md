# FramePad X201 Tablet (ThinkPad X201 Tablet + Framework 13)

**먼저 한마디.** 제가 끄적인 글 때문에 누군가가, 혹은 어느 회사가 기분 상하는 일은 없었으면 합니다. 저는 집단농장에서 태어났고, 손재주든 글재주든 현장에서 몸으로 익힌 게 전부입니다.

---

흐르는 물, 타오르는 불, 바뀌는 계절은 아무리 바라봐도 질리지 않습니다.

오래된 ThinkPad도 다른 노트북에 비하면 거의 영원히 작동할 것 같습니다. 아쉽게도 수명이 길다고 성능까지 세월을 따라가 주지는 않더군요. 그래서 오래된 X201 Tablet을 업그레이드하기 시작했습니다.
